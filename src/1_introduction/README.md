# Введение
## Архитектура потока данных

Процесс работы Persona Exporter можно верхнеуровнево описать следующей схемой:

```mermaid
graph TD
    OS[Операционная система с которой хотите собирать метрики] 
    -->|Сбор метрик: CPU, RAM, Сеть, Датчики, Диски, Процессы| PE(Persona Exporter)
    PE 
    -->|POST-запрос: JSON / Line Protocol| TSDB[(Сервер мониторинга<br>InfluxDB / Victoria Metrics *или любая другая поддерживающая формат данных Line Protocol*)]
```
