# Процессор

Блок конфигурации: `metrics.cpu`

Предоставляет детальную информацию об общей утилизации процессорного времени, количестве ядер, а также о текущей частоте и нагрузке на каждый логический поток сервера.

## Список собираемых метрик

### `global_cpu_usage`
* **Тип**: Float (Percent)
* **Описание**: Общая загрузка процессора в системе по всем ядрам.
* **Пример значения**: `8.08`

### `threads`
* **Тип**: Integer
* **Описание**: Общее количество доступных логических потоков в системе.
* **Пример значения**: `8`

### `physical_core_count`
* **Тип**: Integer
* **Описание**: Количество физических процессорных ядер на сокете.
* **Приmer значения**: `4`

### `cpu_cores.os_name`
* **Тип**: String
* **Описание**: Системный идентификатор логического потока (ядра).
* **Пример значения**: `"cpu0"`

### `cpu_cores.frequency`
* **Тип**: Integer (MHz)
* **Описание**: Текущая тактовая частота работы конкретного потока.
* **Пример значения**: `2336`

### `cpu_cores.cpu_usage`
* **Тип**: Float (Percent)
* **Описание**: Индивидуальный уровень утилизации конкретного логического потока.
* **Пример значения**: `17.17`
