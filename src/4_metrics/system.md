# Система 

Блок конфигурации: `metrics.system`

Раздел собирает общие системные метрики операционной системы, такие как имя дистрибутива, версия ядра, 
время непрерывной работы (аптайм) и показатели средней загрузки (Load Average).

## Список собираемых метрик

### `system_name`
* **Тип**: String (Тег / Строковое значение)
* **Описание**: Название операционной системы (например, `NixOS`, `Ubuntu`).
* **Пример значения**: `"NixOS"`

### `system_kernel_version`
* **Тип**: String
* **Описание**: Полная версия установленного ядра Linux.
* **Пример значения**: `"7.0.10-zen1"`

### `system_kernel_long_version`
* **Тип**: String
* **Описание**: Расширенная информация о сборке и архитектуре ядра.
* **Пример значения**: `"Linux 7.0.10-zen1"`

### `system_distribution_id`
* **Тип**: String
* **Описание**: Уникальный идентификатор дистрибутива в системе.
* **Пример значения**: `"nixos"`

### `system_boot_time`
* **Тип**: Integer (Unix Timestamp)
* **Описание**: Время загрузки системы в секундах с начала эпохи Unix.
* **Пример значения**: `1791436434`

### `system_uptime`
* **Тип**: Integer (Seconds)
* **Описание**: Время непрерывной работы операционной системы с момента последней загрузки.
* **Пример значения**: `7505`

### `system_cpu_arch`
* **Тип**: String
* **Описание**: Архитектура центрального процессора хоста.
* **Пример значения**: `"x86_64"`

### `system_os_version`
* **Тип**: String
* **Описание**: Версия релиза операционной системы.
* **Пример значения**: `"26.05"`

### `system_host_name`
* **Тип**: String
* **Описание**: Сетевое имя хоста (hostname) машины.
* **Пример значения**: `"nikita"`

### `system_load_average_one`
* **Тип**: Float
* **Описание**: Средняя загрузка процессора за последнюю 1 минуту.
* **Пример значения**: `1.93`

### `system_load_average_five`
* **Тип**: Float
* **Описание**: Средняя загрузка процессора за последние 5 минут.
* **Пример значения**: `1.87`

### `system_load_average_fifteen`
* **Тип**: Float
* **Описание**: Средняя загрузка процессора за последние 15 минут.
* **Пример значения**: `1.72`
