# Процессы

Блок конфигурации: `metrics.processes`

Собирает глубокую метрику по выполняющимся в системе процессам. Имеет встроенную сортировку и ограничение лимита (по умолчанию топ-5 по ресурсоемкости).

## Структура метрик процесса

Каждая строка процесса включает тег `program_id` (PID) и `name` (имя бинарника/процесса).

### `process_status`
* **Тип**: String (Enum)
* **Описание**: Текущее состояние процесса. Допустимые значения: `Run`, `Sleep`, `Idle`, `Zombie` и др.
* **Пример значения**: `"Sleep"`

### `process_cpu_usage_per_thread`
* **Тип**: Float (Проценты)
* **Описание**: Утилизация ресурсов процессора в пересчете на один поток. Может превышать 100% на многопоточных CPU.
* **Пример значения**: `38.38`

### `process_global_cpu_usage`
* **Тип**: Float (Проценты)
* **Описание**: Абсолютная загрузка процессора относительно суммарной мощности всех ядер хоста.
* **Пример значения**: `4.79`

### `process_memory_usage`
* **Тип**: Integer (Bytes)
* **Описание**: Объем физической оперативной памяти, занятый процессом (RSS).
* **Пример значения**: `3145568256`

### `process_virtual_memory`
* **Тип**: Integer (Bytes)
* **Описание**: Объем выделенной виртуальной памяти под процесс (VSZ).
* **Пример значения**: `7664267264`

### `process_run_time`
* **Тип**: Integer (Seconds)
* **Описание**: Время активного выполнения процесса в секундах.
* **Пример значения**: `2902`

### `process_start_time`
* **Тип**: Integer (Unix Timestamp)
* **Описание**: Время запуска процесса.
* **Пример значения**: `1791441037`

### Счетчики ввода-вывода процесса (`disk_usage`):
* `process_disk_read_bytes`: Прочитано байт за текущую итерацию (`0`).
* `process_disk_written_bytes`: Записано байт за текущую итерацию (`0`).
* `process_disk_total_read_bytes`: Всего прочитано процессом с момента старта (`1134235648`).
* `process_disk_total_written_bytes`: Всего записано процессом с момента старта (`1063022592`).

### Системные атрибуты:
* `process_user_id`: UID владельца (`"1000"`).
* `process_group_id`: GID группы процесса (`"100"`).
