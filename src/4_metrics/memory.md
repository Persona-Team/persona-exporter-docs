# Оперативная память

Блок конфигурации: `metrics.memory`

Предоставляет детальную информацию о состоянии физической оперативной памяти (RAM) и раздела подкачки (Swap) на сервере. Все объемные показатели измеряются в байтах.

## Список собираемых метрик

### `memory_total`
* **Тип**: Integer (Bytes)
* **Описание**: Общий объем установленной физической оперативной памяти (RAM).
* **Пример значения**: `16543596544` (15.4 ГБ)

### `memory_used`
* **Тип**: Integer (Bytes)
* **Описание**: Объем памяти, занятый процессами, ядром и буферами ОС.
* **Пример значения**: `10497908736`

### `memory_free`
* **Тип**: Integer (Bytes)
* **Описание**: Полностью свободная нераспределенная оперативная память.
* **Пример значения**: `1207029760`

### `memory_available`
* **Тип**: Integer (Bytes)
* **Описание**: Реально доступный объем памяти для запуска новых приложений без ухода в swap (учитывает кэш).
* **Пример значения**: `6045687808`

### `memory_swap_total`
* **Тип**: Integer (Bytes)
* **Описание**: Общий выделенный объем виртуального пространства подкачки (Swap-файлы или разделы).
* **Пример значения**: `25451552768` (23.7 ГБ)

### `memory_swap_used`
* **Тип**: Integer (Bytes)
* **Описание**: Используемый в данный момент объем пространства подкачки.
* **Пример значения**: `848490496`

### `memory_swap_free`
* **Типнется**: Integer (Bytes)
* **Описание**: Свободный объем в пространстве подкачки.
* **Пример значения**: `24603062272`
