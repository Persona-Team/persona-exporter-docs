# Сеть

Блок конфигурации: `metrics.network`

Агрегирует статистику сетевой активности хоста, объемы входящего и исходящего трафика, а также количество аппаратных или программных ошибок на уровне сетевых интерфейсов. Все объемные показатели измеряются в байтах.

## Список собираемых метрик

### `interface_name`
* **Тип**: String
* **Описание**: Системное имя сетевого интерфейса в ОС.
* **Пример значения**: `"wlp0s20f3"`

### `total_rx_bytes`
* **Тип**: Integer (Bytes)
* **Описание**: Накапливаемый счетчик принятых байт (входящий трафик) с момента запуска интерфейса.
* **Пример значения**: `335486916` (319.9 МБ)

### `total_rx_packets`
* **Тип**: Integer
* **Описание**: Общее количество успешно принятых сетевых пакетов.
* **Пример значения**: `172934`

### `total_rx_errors`
* **Тип**: Integer
* **Описание**: Счетчик зафиксированных ошибок во время приема сетевых данных.
* **Пример значения**: `0`

### `total_tx_bytes`
* **Тип**: Integer (Bytes)
* **Описание**: Накапливаемый счетчик переданных байт (исходящий трафик) с момента запуска интерфейса.
* **Пример значения**: `44727435` (42.6 МБ)

### `total_tx_packets`
* **Тип**: Integer
* **Описание**: Общее количество успешно отправленных сетевых пакетов.
* **Пример значения**: `172934`

### `total_tx_errors`
* **Тип**: Integer
* **Описание**: Счетчик зафиксированных ошибок во время передачи сетевых данных.
* **Пример значения**: `0`
