# Дисковое пространство

Блок конфигурации: `metrics.disks`

Отслеживает состояние смонтированных файловых систем, доступное место на дисках (SSD/HDD), а также счетчики ввода-вывода (I/O) для каждого раздела.

## Список собираемых метрик (в разрезе точек монтирования)

Каждая запись маркируется тегами: `name` (раздел устройства), `mount_point` (точка монтирования), `file_system` (тип ФС) и `kind` (тип накопителя).

### `disk_total_space`
* **Тип**: Integer (Bytes)
* **Описание**: Общий емкостный объем файловой системы раздела.
* **Пример значения**: `501889327104` (~467 ГБ)

### `disk_available_space`
* **Тип**: Integer (Bytes)
* **Описание**: Объем пространства, доступный непривилегированным пользователям.
* **Пример значения**: `152911683584`

### `disk_used_space`
* **Тип**: Integer (Bytes)
* **Описание**: Занятый объем дискового пространства на разделе.
* **Пример значения**: `348977643520`

### `disk_read_bytes`
* **Тип**: Integer (Bytes)
* **Описание**: Количество байт, прочитанных с диска за текущий интервал опроса.
* **Пример значения**: `0`

### `disk_written_bytes`
* **Тип**: Integer (Bytes)
* **Описание**: Количество байт, записанных на диск за текущий интервал опроса.
* **Пример значения**: `0`

### `disk_total_read_bytes`
* **Тип**: Integer (Bytes)
* **Описание**: Нарастающий итог (счетчик) всех прочитанных байт с момента старта системы.
* **Пример значения**: `12427323392`

### `disk_total_written_bytes`
* **Тип**: Integer (Bytes)
* **Описание**: Нарастающий итог (счетчик) всех записанных байт за все время работы ОС.
* **Пример значения**: `5401546752`

### `disk_is_read_only`
* **Тип**: Boolean
* **Описание**: Флаг режима "только чтение". Полезно для детекции аварийного перемонтирования ФС.
* **Пример значения**: `false` (или `true` для `/nix/store`)

### `disk_is_removable`
* **Тип**: Boolean
* **Описание**: Флаг съемного накопителя (USB-флешки, внешние диски).
* **Пример значения**: `false`
