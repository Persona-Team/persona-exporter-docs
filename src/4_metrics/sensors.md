# Датчики аппаратных компонентов

Блок конфигурации: `metrics.components`

Считывает показатели физических температурных датчиков (через интерфейсы hwmon ядра Linux) для мониторинга аппаратного перегрева процессора, материнской платы и дисков.

## Список собираемых метрик

Метрики группируются по уникальному строковому тегу датчика `id` и системному имени `name`.

### `component_temp`
* **Тип**: Float (Градусы Цельсия)
* **Описание**: Текущая температура, зафиксированная датчиком в данный момент.
* **Пример значения**: `68.0`

### `component_max_temp`
* **Тип**: Float (Градусы Цельсия)
* **Описание**: Максимальное пиковое значение температуры, зафиксированное датчиком за текущую сессию мониторинга.
* **Пример значения**: `80.0`

### `component_critical_temp`
* **Тип**: Float (Градусы Цельсия)
* **Описание**: Порог критической температуры, установленный производителем оборудования, при превышении которого наступает троттлинг или аварийное выключение.
* **Пример значения**: `100.0` (или `0.0`, если лимит не задан драйвером).
